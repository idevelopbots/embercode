Privacy Policy

Last Updated: November 2026

1. What We Value as Privacy

Your privacy comes first. Cardinal operates on a strict data minimization principle: we only store the bare minimum technical identifiers required for commands and server settings to function properly. We never read private messages, log casual chat history, or sell, rent, or share any data with third parties.

2. Data We Collect

When Cardinal is added to a server or used via slash commands, we may store the following non-sensitive Discord identifiers:

  • Server (Guild) IDs: Used to save your server's custom configuration, prefixes, and feature toggles.
  • Channel & Role IDs: Stored only when configured by an administrator (such as welcome channels, log channels, or auto-assignable roles).
  • User IDs: Temporarily or permanently stored when tied to moderation records (such as warnings, timeouts, or open support tickets).

3. Data Retention & Deletion

Server configuration data is automatically purged when Cardinal is removed from your server. If you would like to request manual deletion of any user-specific moderation logs or stored records, please reach out to our team through the official Support Server linked on the home page.
