Privacy Policy

Last updated: November 20, 2026

1. Information We Collect

Canvas collects only the information needed to function: guild data, user data, and basic usage information such as command invocations.

2. Guild Data

Canvas may store server configuration data, channel IDs, and role IDs required for operation, along with the guild ID and your chosen settings.

3. User Data

Canvas may store user IDs where needed for features to work. We do not collect messages, email addresses, or passwords.

4. How Data Is Used

  • To run and maintain Canvas features
  • To save and apply your server settings
  • To troubleshoot issues and improve reliability

5. Data Storage

Data is stored in secured databases and is used only for the operation of Canvas.

6. Data Security

We use access controls and reasonable safeguards to protect stored data. No system is completely secure, but we work to limit exposure and respond to issues quickly.

7. Data Sharing

We do not sell your data. Information is shared only with infrastructure providers needed to run Canvas, or when required by law.

8. Data Retention

Server data is kept while Canvas is in your server. When the bot is removed or on request, related data is deleted within a reasonable period.

9. User Rights

You may request access to, correction of, or deletion of data associated with your user ID or server by contacting us.

10. Contact Information

Questions? Join our support server and open a ticket, and the Canvas team will respond.
