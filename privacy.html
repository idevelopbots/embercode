Waypoint Bot - Privacy Policy

This Privacy Policy explains how Waypoint handles data.

1. Information Collected

Waypoint only stores minimal server configuration data required for its features. No personal user data is collected intentionally.

2. Data Storage

Stored data is kept securely and only used for bot functionality. Data may be removed automatically if no longer needed.

3. Third Parties

Waypoint does not share data with third parties. All processing occurs within the bot’s systems.

4. User Rights

Server administrators may request deletion of stored configuration data at any time.

5. Changes

This policy may be updated as Waypoint evolves. Continued use of the bot implies acceptance of updated terms.
