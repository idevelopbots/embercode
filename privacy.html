Privacy Policy

Status: Active
Effective Date: 2026

01. Information Collected

Harmony stores minimal server configuration data required for its core features. No personal user data is intentionally collected or tracked across external sessions.

02. Data Storage

Stored configuration data is kept securely in encrypted databases and removed automatically when no longer needed or immediately upon direct request from authorized server administrators.

03. Third Parties

Harmony does not share, rent, or sell any data to third parties. All query processing and indexing occurs exclusively within the bot’s internal architecture.

04. User Rights

Server administrators retain full ownership of their data and maintain the absolute right to request instant deletion of stored configuration logs at any time via support channels.

05. Policy Changes

This privacy framework may be updated as Harmony evolves. Continued operation or authorization of the bot within your server infrastructure implies acceptance of updated terms.
