Bot Commands

/help

Displays an interactive menu listing all available bot commands and feature guides.

/ping

Check the response latency and API websocket ping for Velocity.

/serverinfo

Show detailed information about the current Discord server, including member count and creation date.

/userinfo [user]

Displays profile information, join date, and assigned roles for a specified user.

/play [song/url]

Play high-quality audio in your current voice channel from supported streaming services.

/clear [amount]

Bulk delete up to 100 messages in the current text channel (requires Moderator permissions).
