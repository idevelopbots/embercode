Commands Reference

Prefix: / (Slash Commands)
Total: 5 Active
/invite General

Generate secure authorization links to deploy Waypoint directly into your own Discord server infrastructure.

/vm-enable Voice

Activate the automated VoiceMaster module to provision dynamic, user-managed voice channels on demand.

/vm-disable Voice

Deactivate the VoiceMaster module and clean up any remaining automated temporary voice channel hubs.

/welcome <channel> Config

Configure a dedicated text channel to automatically greet and onboard newly joined community members.

/ping Utility

Perform a real-time diagnostic ping test to verify bot response latency and gateway connectivity metrics.
