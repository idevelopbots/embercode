Canvas: Privacy Policy

Last Updated: July 2026

1. Overview

Canvas (“the bot,” “we,” “our,” or “us”) respects your privacy. This Privacy Policy explains what data we collect, how we use it, and how it is stored. By using Canvas, you agree to this policy.

2. Information We Collect

  • User IDs: To identify command usage and permissions.
  • Server (Guild) IDs: To store server-specific settings.
  • Channel IDs: When needed for configuration or features.
  • Message content: Only when required for specific commands you use.
  • Command usage data: For debugging, analytics, and improvement.

We do not intentionally collect sensitive personal information.

3. How We Use Data

  • Provide bot functionality
  • Store server settings and preferences
  • Improve performance and reliability
  • Prevent abuse, spam, or misuse
  • Debug errors and maintain stability

4. Data Storage

  • Data is stored securely using standard security practices.
  • Data is kept only as long as necessary for bot functionality.
  • Some settings may remain until manually deleted or reset.

5. Data Sharing

We do not sell, rent, or trade your data. Data may only be shared when:

  • Required by law or legal request.
  • Needed to protect Canvas’s security and integrity.
  • Used with trusted infrastructure providers (under confidentiality agreements).

6. User Control & Deletion

You may request deletion of your data at any time. This may include:

  • Server settings
  • Stored user preferences
  • Associated identifiers

To request deletion, contact the developer or support server.

7. Data Security

  • We use reasonable security measures to protect data.
  • We try our very best to protect sensitive user information.
  • No system is 100% secure. By using Canvas, you accept this risk.

8. Third-Party Services

  • Canvas may use third-party services (hosting, databases, etc.).
  • These services only process data to keep the bot running.
  • They are not allowed to use your data for other purposes.

9. Children’s Privacy

  • Canvas is intended for users aged 13+ (or the minimum age in your country).
  • We do not knowingly collect data from users under this age.

10. Changes to This Policy

  • We may update this Privacy Policy at any time.
  • Continued use of Canvas means you accept changes.
  • Updates may be announced in the official support server.

11. Contact

For questions or data requests, contact the developer through the official support server or the bot profile contact method.
